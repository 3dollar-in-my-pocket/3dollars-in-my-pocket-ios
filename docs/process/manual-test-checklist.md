# 수동 테스트 체크리스트

자동 테스트(ViewModel/Service/Decoding)가 못 덮는 범위를 사람이 어디까지 봐야 하는지 정한다.
PR 본문의 **TC 섹션**에 들어가는 체크리스트의 출처이며, `/3dollars:pr-body`가 아래 규칙대로 자동으로 채운다.

## 1. 자동화하지 않는 것 (= 수동 TC)

`docs/process/testing.md`와 같은 기준. 테크스펙 TC가 아래에 해당하면 코드로 만들지 않고 수동 TC로 분류한다.

| 범주 | 예 | 확인 방법 |
|---|---|---|
| 애니메이션·제스처 | 마커 확대, 바텀시트 스냅, 스와이프 삭제 | `3dollars:simulator-test` 영상 |
| 지도 렌더링 | 네이버맵 마커·클러스터·카메라 이동 | 시뮬레이터 스크린샷 |
| 외부 SDK | 카카오 로그인·공유, 애플 로그인, 애드몹 | 실기기 (시뮬레이터 불가한 것 있음) |
| OS 권한 팝업 | 위치·사진·알림·ATT | 시뮬레이터 설정 초기화 후 재현 |
| 푸시 수신·딥링크 진입 | 알림 탭 → 화면, `dollars://` 스킴 | `simctl push` / `simctl openurl` |
| 결제·스토어 | 인앱 리뷰 요청, 앱스토어 이동 | 실기기 |

## 2. 화면 변경 PR 공통 체크 항목

**diff에 UI 파일이 있을 때만** PR TC 섹션에 자동으로 붙는다 (로직·CI·문서 PR에는 안 붙음).
UI 파일 판정: `*View.swift`, `*ViewController.swift`, `*Cell.swift`, `*BottomSheet*.swift`, `Resources/**`, `Modules/Core/DesignSystem/**`, `Modules/Core/SDU/**`.

```markdown
- [ ] 공통 — 다크모드에서 색·아이콘 깨짐 없음
- [ ] 공통 — 작은 화면(iPhone SE급)·큰 화면(Pro Max)에서 레이아웃 깨짐 없음
- [ ] 공통 — 긴 텍스트/빈 데이터/0건에서 레이아웃 유지
- [ ] 공통 — 오프라인·느린 네트워크에서 로딩/에러 상태 표시
- [ ] 공통 — 비로그인(익명) 상태에서 진입 시 동작
```

필요 없는 항목은 작성자가 지우되, 지운 이유를 한 단어로 남긴다 (예: `~~다크모드~~ 색 변경 없음`).

## 3. 영역별 추가 항목

diff가 아래 경로/키워드를 건드리면 해당 블록을 추가한다.

| 트리거 (경로·키워드) | 추가 항목 |
|---|---|
| `Home/**`, `NMF`, `MapView` | 마커 탭·클러스터·현위치 이동·지도 드래그 후 재검색 |
| `DeepLink`, `dollars://`, `universal` | 콜드 스타트/백그라운드 두 경우 모두에서 딥링크 진입 |
| `Notification`, `service-extension`, `content-extension` | 푸시 수신(포그라운드/백그라운드), 알림 탭 랜딩 |
| `Kakao`, `Apple`, `Signin` | 로그인 성공·취소·실패, 로그아웃 후 재로그인 |
| `Admob`, `AdBanner` | 광고 로드 실패 시 레이아웃, 광고 없는 상태 |
| `Photo`, `ImageUpload`, `Camera` | 권한 거부 상태, 대용량 사진, 업로드 중 화면 이탈 |
| `Location`, `CLLocation` | 위치 권한 거부·"앱 사용 중만 허용"·정확도 낮음 |
| `Write/**` | 마법사 중간 이탈 후 복귀, 뒤로가기로 입력 유지 |

## 4. PR 본문에 적는 법

`/3dollars:pr-body`가 TC 섹션을 이렇게 만든다:

```markdown
## TC
- [ ] TC-2 — 마커 확대 애니메이션 (수동)          ← 테크스펙 TC 중 수동 분류
- [ ] 공통 — 다크모드 …                            ← 2절 (UI 파일 있을 때만)
- [ ] 지도 — 마커 탭·클러스터·현위치 이동 …          ← 3절 (트리거 매칭 시)
(자동 테스트 결과는 CI 코멘트 참고)
```

- 체크는 **작성자**가 PR 올리기 전에 한다. 리뷰어는 체크되지 않은 항목이 있으면 머지하지 않는다.
- 증거가 필요한 항목(애니메이션·지도)은 "증거" 섹션의 스크린샷/영상 링크로 대신한다.
