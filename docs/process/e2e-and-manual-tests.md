# 자동화·수동 테스트 체크리스트

유닛 테스트 코드가 못 덮는 범위를 **에이전트가 시뮬레이터로 할 것(자동화)** 과 **사람이 실기기로 할 것(수동)** 으로 가른다.
계층 정의는 `docs/process/testing.md`("테스트의 세 계층"). PR 본문의 **TC 섹션**에 들어가는 체크리스트의 출처이며, `/3dollars:pr-body`가 아래 규칙대로 자동으로 채운다.

## 1. 유닛 코드로 덮지 않는 것의 분류

경계는 하나다: **시뮬레이터로 그 상황을 만들 수 있으면 자동화, 없으면 수동.** 판정이 사람 눈이어야 한다는 건 자동화를 막는 이유가 아니다(스크린샷·영상이 증거).

| 범주 | 예 | 계층 | 확인 방법 |
|---|---|---|---|
| 화면 진입·전환 | 버튼 탭 → 화면 이동, 목록 갱신 | **자동화** | `simulator-test` 스크린샷 |
| 애니메이션·제스처 | 마커 확대, 바텀시트 스냅, 스와이프 삭제 | **자동화** | `simulator-test` 영상 |
| 지도 렌더링 | 네이버맵 마커·클러스터·카메라 이동 | **자동화** | 시뮬레이터 스크린샷 |
| OS 권한 팝업 | 위치·사진·알림·ATT | **자동화** | `simctl privacy reset` 후 재현 |
| 푸시 수신·딥링크 진입 | 알림 탭 → 화면, `dollars://` 스킴 | **자동화** | `simctl push` / `simctl openurl` |
| 네트워크 상태 | 오프라인·느린 응답·에러 코드 | **자동화** | Proxyman Scripting 으로 지연·에러 주입 |
| 외부 SDK 로그인·공유 | 카카오 로그인·공유, 애플 로그인 | **수동** | 실기기 (시뮬레이터에 앱·계정 없음) |
| 광고 | 애드몹 실광고 노출·실패 | **수동** | 실기기 |
| 결제·스토어 | 인앱 리뷰 요청, 앱스토어 이동 | **수동** | 실기기 |

자동화로 분류했는데 `simulator-test` 가 `BLOCKED`/`UNCLEAR` 로 끝나면, 그 TC 만 수동으로 내리고 **이유를 PR 에 한 줄 남긴다.**

## 2. 화면 변경 PR 공통 체크 항목

**diff에 UI 파일이 있을 때만** PR TC 섹션에 자동으로 붙는다 (로직·CI·문서 PR에는 안 붙음).
UI 파일 판정: `*View.swift`, `*ViewController.swift`, `*Cell.swift`, `*BottomSheet*.swift`, `Resources/**`, `Modules/Core/DesignSystem/**`, `Modules/Core/SDU/**`.

전부 **자동화 계층**이다 — 시뮬레이터 설정·기기 선택·Proxyman 으로 상태를 만들 수 있다. 작성자가 손으로 확인하는 게 아니라 `simulator-test` 가 돌고 증거를 남긴다.

```markdown
- [ ] 공통 — 다크모드에서 색·아이콘 깨짐 없음
- [ ] 공통 — 작은 화면(iPhone SE급)·큰 화면(Pro Max)에서 레이아웃 깨짐 없음
- [ ] 공통 — 긴 텍스트/빈 데이터/0건에서 레이아웃 유지
- [ ] 공통 — 오프라인·느린 네트워크에서 로딩/에러 상태 표시
- [ ] 공통 — 비로그인(익명) 상태에서 진입 시 동작
```

필요 없는 항목은 작성자가 지우되, 지운 이유를 한 단어로 남긴다 (예: `~~다크모드~~ 색 변경 없음`).

## 3. 영역별 추가 항목

diff가 아래 경로/키워드를 건드리면 해당 블록을 추가한다.

| 트리거 (경로·키워드) | 추가 항목 |
|---|---|
| `Home/**`, `NMF`, `MapView` | 마커 탭·클러스터·현위치 이동·지도 드래그 후 재검색 |
| `DeepLink`, `dollars://`, `universal` | 콜드 스타트/백그라운드 두 경우 모두에서 딥링크 진입 |
| `Notification`, `service-extension`, `content-extension` | 푸시 수신(포그라운드/백그라운드), 알림 탭 랜딩 |
| `Kakao`, `Apple`, `Signin` | 로그인 성공·취소·실패, 로그아웃 후 재로그인 |
| `Admob`, `AdBanner` | 광고 로드 실패 시 레이아웃, 광고 없는 상태 |
| `Photo`, `ImageUpload`, `Camera` | 권한 거부 상태, 대용량 사진, 업로드 중 화면 이탈 |
| `Location`, `CLLocation` | 위치 권한 거부·"앱 사용 중만 허용"·정확도 낮음 |
| `Write/**` | 마법사 중간 이탈 후 복귀, 뒤로가기로 입력 유지 |

## 4. PR 본문에 적는 법

`/3dollars:pr-body`가 TC 섹션을 **커버리지 표 + 체크리스트**로 만든다 (표 규칙은 `docs/process/testing.md` "PR에 남기는 것"):

```markdown
## TC
커버리지 3/3

| TC | 내용 | 계층 | 테스트 / 증거 | 결과 |
|---|---|---|---|---|
| TC-1 | 섹션 로드 | 유닛 | `test_TH1234_TC1_…` | ✅ |
| TC-2 | 마커 확대 | 자동화 | marker.mp4 | ✅ PASS |      ← 에이전트가 돌리고 증거 첨부
| TC-7 | 카카오 공유 진입 | 수동 | 아래 체크 | ☐ |

- [ ] TC-7 — 카카오 공유로 진입 (수동, 실기기)                  ← 작성자가 직접
- [x] 공통 — 다크모드 … (자동화) → 증거 dark.png                ← 2절 (UI 파일 있을 때만)
- [ ] 지도 — 마커 탭·클러스터·현위치 이동 … (자동화)             ← 3절 (트리거 매칭 시)
```

- **자동화 스펙 TC** 는 표의 결과 칸에 PASS 와 증거 링크가 함께 있어야 커버다. 증거 없는 PASS 는 PASS 가 아니다.
- **`(수동)` 항목**은 작성자가 실기기로 확인하고 체크한다.
- 리뷰어는 표에 `⚠️ 미커버`·`FAIL` 이 있거나 체크되지 않은 항목이 있으면 머지하지 않는다.
